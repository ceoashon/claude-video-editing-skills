# Shorts cutter

## 1. Pick the clips
Read the full transcript of the long form (with word timestamps). Pick 5–8 moments, or as few as 3 from a short video. Only keep the ones that are actually good. Each must:
- **Stand alone.** A stranger understands it with zero context.
- **Hook in the first 2 seconds:** a number, a question or a bold claim. If the best line is mid-clip, start there.
- **Run 20–60 s.** Cut setup ruthlessly.
- **End on a payoff,** not a trailing "so yeah".

For each clip, write: start/end times, the hook line, why it works, and a tag for testing (hook type: number / question / claim; length: short / mid / long; topic: money / how-to / story).

## 2. Cut
- Use the same word-snapped cutting as the long form: cut at the quietest point near word boundaries, shrink pauses over 0.6 s to 0.3 s.
- Reframe 16:9 → 9:16 around the face (crop centred on the face; keep headroom).
- Process the voice the same way as the long form (about -14 LUFS, true peak ≤ -1 dBTP).

## 3. Style (keep it clean)
- One caption line at a time, white, bold, centred in the lower third, synced to words.
- One hook line at the top for the first ~2 s.
- Few or no extra graphics. Heavy editing styles fight the footage. One focal point at a time.

## 4. Deliver
One file per short, named `NN - Title.mp4`, plus a text file with each short's caption, hashtags and test tags. Post the same file and caption on all platforms so results compare fairly.
